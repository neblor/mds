## 设计目标

一个默写辅助工具，浅色高雅风格，单窗口桌面应用（Electron）。
画布尺寸统一 **1120×820**，与 Electron 主窗口默认尺寸、Web 端 `max-w-[1120px]` 容器一致；
页面外圈的 `#E6E9EC` 不属于应用内容，故不进设计稿。

**主色**：`$primary #4EA3A0`（青绿）；**辅色**：`$gold #EFC055`（星标/鼓励）。
语义色：`$success #7FB88C` / `$success-bg #EAF4EC`、`$error #DE8071` / `$error-bg #F9EBE8`。

## 伸缩与滚动（弹性区规则）

> 窗口固定 1120×820（高分屏上已占满高度，**不再扩大**）：新功能一律靠“用好既有空间”实现，不靠加高。

**固定区**（任何状态、任何模式下位置都不变）：
`Header 63` → `词源切换条 34` → `词源卡 63` → `Controls 43` → `[错误条 44，仅出错时]` → `Actions 51`

**唯一弹性区**：单词表 / 本次取词卡片（`height: fill_container`）
- 卡内再分两层：**卡头**（`本次取词 · 20 词` + 复习/新词徽标 + `已默 8 / 20` + `重新取词`，固定）与 **列表体**（`fill_container` + `clip`，溢出即滚动）
- 词少时卡片变高（留白在卡内，视觉上是“内容区大”）；词多时卡片**不涨**，改为列表体内部滚动
- 所以：**词再多也不会把 Controls / 按钮顶出界面**；错误条出现时只是这张卡变矮 64px，其它元素纹丝不动

**空态也占满**：`Empty Words` / `Empty Vocab` 两个占位层同样是 `fill_container` 且内容居中——空词库时是“大卡片 + 居中引导”，不是“顶部一行字 + 底部一大块空白”。

**对应实现（Tailwind 口径，照此落）**：
- 根：`flex h-full flex-col gap-5 p-7`
- 弹性卡：`flex flex-1 min-h-0 flex-col`（**`min-h-0` 是关键**，否则 flex 子项不会收缩、滚动失效）
- 列表体：`flex-1 min-h-0 overflow-y-auto`
- 固定行：不加 `flex-1`，保持自然高度
- 空态：在列表体内 `flex h-full items-center justify-center`

**易错点（已规避，改版时别改回去）**：
1. 不让两个兄弟同时 `fill_container`（旧版的“弹性卡 + 底部 Spacer”就是这个问题）——空间分配会互相抢
2. 列表体必须自己 `clip`/`overflow` 承接溢出，不能让卡片自己撑高
3. 条件节点（错误条 / 空态 / 本次取词）必须**互斥**，避免两个 `fill_container` 兄弟同时存在
4. 设置面板加第五张卡就会超过 820 → 已把「倍率调整 / 倒计时数字 / 期望保持率」并成一张 `Params Card` 并收紧内边距；
   2026-10-13 又在 AI 服务卡里加了一行「生成级别」。
   **第八批（2026-11-15）**：这一行此前的画板里根本没有，现在补上，并把面板整体收紧 ——
   卡片内边距 18 → 14、卡片内 gap 10 → 8、面板 gap 14 → 10、输入行 padding 10 → 8，面板总高 **854 → 754**，
   在 820 窗口里**完整可见、不需要内部滚动**。实现里若维持原间距（实测 ~840）则会出现 `max-h 90% + 内部滚动`，
   两者差异属「参数收紧」而非结构差异；是否把实现同步到 754 见根 `FUTURE.md`。

## 与实现的一处刻意差异：字体

实现里 `--font-heading / --font-body / --font-data` **三者同族**（Sarasa UI SC，Source Han Sans 派生，本机系统字体），
设计稿里三个变量统一用 **Noto Sans SC** 代位（同为思源黑体家族，观感最接近）。
2026-11-15 起该 family 已在项目字体注册表（`.design/__preset.ptr`）里注册为 **web 字体**（Google Fonts CSS），
渲染/截图不再退到系统兜底；WSL 里仍会报 `Inter Variable / Noto Sans SC Variable / Segoe UI` 缺失，那是渲染器的候选栈提示，不影响这几块画布。
如果你希望设计稿恢复「标题衬线 / 数据等宽」的字形区分，那就需要在实现里真正引入对应字体——请审阅时定夺。

## 交互规则（摘自 AGENTS.md，仍是当前实现的口径）

- 每轮时长 = `max(字母数×系数×档位, 音频时长×播报遍数) + 1.5s`；释义模式再加 `释义词数×0.5s`；整体 × 倍率调整
- 播报遍数：释义模式 3 遍；非释义 <6 字母 2 遍、≥6 字母 3 遍
- 跳转解耦：倒计时结束 / 语音播完 各自打标记，两者都完成才进下一轮；
  例外：赛博提交完全部输入后不等倒计时（等当前遍播完即走）、书写模式未发声时按空格可跳
- 对错：仅赛博模式判断，单词严格匹配（trim 后大小写/标点/空格完全一致）；释义与中文词由 AI 批改，失败/中止降级本地宽松匹配并在结果页提示
- 结果页按 Esc 与点关闭完全等价：停止试听并回到准备态，词库保留
- 词库每次新增、批量导入、删除或清空时立即写入 localStorage，刷新或重启后恢复
- 批量导入使用任意空白字符、英文逗号或英文分号切分；忽略空项、本批重复项和已有项
- 键盘流：模式条 ←/→/Home/End 切换；弹层打开即聚焦输入区，`Ctrl/Cmd + Enter` 确认导入，Esc 关闭；`Let's Go!` 自动聚焦回车开始

## Phase 1 界面的补充交互规则（18–23）

- **词源双模式**：切换条只管「词从哪来」，不影响下面的快中慢 / 单词·释义·中文词；切模式不弹任何确认
- **录入模式不进复习**：它是“练一把”的临时路径；想让词有复习计划，先加进词表
- **词表模式不选词**：本场默哪些词完全由 FSRS-6 排（到期优先 + 新词补足），用户只调「本次默几个」（步进器 5–30，步长 5，默认 20，禁止手动输入，即改即存）。**这个数字是「这一次取几个」，不是「今天一共默几个」**（2026-10-24 更正）。候选池取推荐序列前 100；本批前 K 个必默（5→2、10→3 … 30→7），其余从池内剩余随机（2026-10-28）
- **本次取词**：卡头显示本批词数、复习/新词构成、`已默 x / N`（x 与 N 是**同一批**的两个数，跨批次不累计）；已默词在胶囊里带勾且变淡；`重新取词`按当前数字再取一批（不改卡状态，刷新中显示旋转，完成后显示「已刷新」）；结算后本批词面冻结，不会自动跳成下一批
- **资源词表只读**：没有编辑/删除入口；要改只能 `复制为自建词表`（把资源词表整表拷成自建，再增删）
- **自建词表可编辑**：加词（回车）、批量导入、点词右侧 × 删除；两个导入入口：`从录入的词加入（N）`、`从历史记录导入`；**全部自动去重**
- **键盘流**：20/21 弹层打开即聚焦输入或首个可交互项，Esc 关闭，`Enter` 确认；22 的加词输入框回车即添加且焦点不回跳
- **字体与数字**：队列数量、`已默 x / N`、保持率均用等宽数字（实现里是 `font-data + tabular-nums`）

## Phase 2 界面的补充交互规则（24–29）

- **组句是第四种内容模式**，与单词/释义/中文词并列在同一模式条；与「书写/赛博」正交，但**组句只允许赛博**：
  选中组句时「开始书写默写」置灰（`opacity 0.45`），并在错误条位置显示**信息条**（brand 底色、primary 文字）：
  `组句模式请用赛博默写：选词作答需要在屏幕上完成`
- **候选池**：本场候选词 ≤24 个（词表模式取本次这批词的前 24 词，录入模式取录入表前 24 词），
  卡头显示`候选词 · N 个（已用 x）`；已被填进某个空的词打勾变淡，**不禁用**（同一个词可能要用两次）
- **组句轮**（27）屏幕结构（自上而下，位置固定）：`第 n / N 题` + `选词作答` 胶囊 → 倒计时条（可选数字）
  → 候选词卡（≤24 个胶囊，2–3 行）→ 短文卡（句中内联空槽，**句数/空数由出题方给，不再固定 2–3 句 + 2–4 空**；
  内容超出卡片高度时卡片内滚动，不裁切）→ 底部键盘提示行；卡头`本组 N 个空`按**实际槽位数**统计
- **空槽三态（实现里为四态）**：已填 = 白底 + 1.5px primary 描边 + primary 文字；当前空 = brand 浅底 + 底部 3px primary 下划线 + `选词` 占位；
  未激活的空 = 同样式但下划线为浅灰；**已填且为当前空** = 已填样式 + 3px `brand/30` 光圈（便于点回来改选），
  设计稿只画了当前空与已填空，光圈是实现层补充
- **键盘流（铁律）**：`←→` 在当前空上移动候选、`1–9` 直接选第 n 个候选、`Enter` 填入当前候选、
  `Tab / ↑↓` 换空、`Backspace` 退回上一个空并清除；**全部空填完立即自动提交**（不需要回车）；
  提示行固定为`←→ 选词 · 1–9 快选 · 回车填入 · Tab 换空 · 倒计时结束按已选提交`
- **鼠标流（点选不再需要挪去点下一个空格）**：点候选词胶囊 = 填入当前空并**自动前进到下一个未填空**
  （与 `Enter` 完全同路，走 `cloze-input.ts` 的 `pick` 事件）；点空槽（含已填）= 把当前空切到它上面，
  再点候选词即覆写；不禁用来回点击
- **出题口径**：提示词**平铺直叙只说「要什么」＋真护栏**（`Produce 3 to 6 items / each with 2 to 3 sentences and
  2 to 4 blanks / cover 6 to 16 candidate words`；真护栏只留「输出非 JSON」「编造池外单词」）。
  **难度不用主观定位**（不说 child / kid-friendly），而是用设置里的**生成级别**（小学/初中/高中/大学，默认初中）
  的客观英文描述（`primary-school English (…)` / `junior-high English (…)` / `senior-high English (…)` /
  `college English: CET-4 and CET-6 vocabulary, complex sentence structures`）写进提示词；同一级别也用于英文释义生成。
  **不写**「允许做什么」的假想纠偏（如「重复也是可以的哦」，等于把错规则先念一遍）、**不写**「多写少写也行」的免责话、
  **也不让模型自检**校验层本来就不需要的唯一性（编号重复/跳号一律宽容）——模型没被限制过的事不提。
  校验侧**只拦格式不拦质量**——本地没有模型，判不了题面好不好。硬拦仅限：JSON 形状、`##n` 与 blanks 一一对应、
  答案必须在候选池里（学生选不出来的题跑不了）、以及防跑飞的防护上限（12 题 / 8 句 / 8 空 / 单句 400 字符）。
  放行：题数句数空数多少、同一个词填多个空、一句里两三个 the、候选池里的词没被挖空就出现在句中、
  usedWords 缺失或不一致（该字段只按答案现算）
- **倒计时**：与单词轮同一套口径（句长基准 + 每空选择用时，× 档位 × 倍率）；
  倒计时结束时把未选完的空按空字符串提交，随后立即进入下一题
- **结果页（28）**：每个空一行 = 判定图标 + 单词 + 发音按钮 + `句子：…（答案已填入）`，右侧是「我的选择」（绿/红）；
  得分 `x / N` 按空统计；说明行写`每空独立判定：选中与正确词完全一致即算对（忽略首尾空格）`；
  词表模式下右侧同时显示复习写回结果
- **准备阶段（25）**：组句只在准备阶段做一次 AI 请求（`正在出题…（一次性生成整场题目）`），进度条用**不确定样式**
  （设计中用居中短条表示，实现里是来回滑动的动画）；出题成功后**只为答案词合成音频**（结果页发音可用）
- **失败（26）**：出题失败即结束本场，文案`AI 当前不可用：生成的题目不符合要求（本场已停止）`，
  下面一行提示`不降级、不自动重试；返回后可以再点一次开始`，只提供「返回」
  （注意：这句文案现在只会因为**格式真的跑不了**出现，句数/空数偏差、重复词不再触发）
- **远端清单（29）**：入口在「选择词表」弹层底部的`检查清单更新`；
  弹层里可填**自定义清单地址**（留空只用随包内置清单；实现里允许 http(s)，但拒本机/内网/保留地址，
  跳转逐跳复校、限大小与超时），检查结果按行给出`更新 / 下载 / 已是最新`，底部`更新可用的 N 个`一次性把有变化的词表拉下来

## 第七批：混合模式（2026-10-29，已切 37–40；37 于第八批实体化）

### 规则要点（设计所依）

- 每个词在 **释义 / 中文词 / 短句** 里随机取两种 → 词数 ×2 轮（20 词 = 40 轮）。

  **第 2 次**出现的释义/中文词轮：**只写第二步**（不写单词，不判拼写）。

### 实例机制的真相（重要，别再踩）

paintress 0.8.0 渲染 `ref` 实例时**只应用一层（父节点的直接子节点）纯属性覆盖**：

- `descendants.<直接子节点 id>` 的 `fill / enabled / content / opacity` 生效（例：37 的 `sO7mD.enabled=false` 关掉错误条）；
- **`children` 整体替换不生效**（33/37 换掉整块 Controls 的写法一直是死的）；
- **`descendants.<孙节点 id>` 一律告警 `未命中，已忽略`**（例：`Zy9hV`、`aKfMy`、滑块里的 `r2EJer`）。

所以 18/19 这种只切 `enabled` 的画板还能对上，而 2（空态）、19（无词表按钮）、24（组句选中）、33（音标轮）、37（混合轮）
在画布上长期显示的是普通 C。第八批把这 5 块按「深拷贝 C + 按 id 打补丁 + id 前缀重编」实体化，
画板从此与标题一致；`C · Word Bank 词库页` 仍是模板，但**新增画板不要再用 ref 覆盖改结构**。

**坐标**：41 `(5080,1000)`、42 `(6280,1000)`、43 `(7480,1000)`、44 `(5080,1980)`；
37 保持 `(5080,0)`，33 `(1240,8680)`、24 `(3720,5900)`、2 `(1240,1000)`、19 `(2480,4920)` 原位替换。
