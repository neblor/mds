# 默点啥 mds — 界面设计说明

> 本文件与 `mds.pen` 配套阅读。`.pen` 为加密文件，仅通过 pencil MCP 操作；本文件记录设计意图与功能注解。

## 设计目标

一个默写辅助工具，浅色高雅风格，单窗口桌面应用（deno desktop webview）。

**主色**：浅色背景 + 一个精致的 primary 色 + 辅色（待设计稿定）。

## 界面清单

| 视图 | 说明 | 关键元素 |
| --- | --- | --- |
| 词库管理（准备） | 默认视图 | 标题、单词输入框（回车添加）、横向 flex-wrap 单词列表（点击删除）、清空按钮、速度三档选择（快/中/慢）、"默写释义"开关、`开始书写默写`/`开始赛博默写` 按钮、设置入口 |
| 默写准备 | 点击开始后 | "默写准备中" 进度提示（预生成音频/释义）；释义模式下全屏毛玻璃遮罩 + 中止按钮；完成后显示"准备完成" + `Let's Go!` 按钮 |
| 默写中 | 逐轮 | 进度条（第 n/总数）、倒计时条（可选 0.1s 数字）、语音播报；赛博模式含输入框（带释义时两步输入：单词→释义） |
| 结果 | 默写完 | 答案对照列表、单词对错红/绿标（赛博模式）、`correct/total`、全对撒花效果、关闭按钮（回准备态） |
| 设置 | 弹出/独立面板 | AI baseUrl + key（带范例）、倍率调整、倒计时数字显示开关（localStorage 持久化） |

## 交互规则（摘自 AGENTS.md）

- 每轮时长 = `max(字母数×系数×档位, 音频时长×播报遍数) + 1.5s`；释义模式再加 `释义词数×0.5s`；整体 × 倍率调整
- 播报遍数：释义模式 3 遍；非释义 <6 字母 2 遍、≥6 字母 3 遍
- 跳转解耦：倒计时结束 / 语音播完 各自打标记，两者都完成才进下一轮
- 对错：仅赛博模式判断，严格匹配（trim 后大小写/标点/空格完全一致）；释义不批改
- 结果关闭后回到准备态，词库保留
