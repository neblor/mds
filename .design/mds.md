# 默点啥 mds — 界面设计说明

> 本文件与 `mds.pen` 配套阅读。`.pen` 为加密文件，仅通过 pencil MCP 操作；本文件记录设计意图与功能注解。
> 最后同步：**2026-10-12（Phase 2）**。画布分三批：① 按当前实现（v0.6.0）整体重建的 1–17；② Phase 1（词库 + SRS）新增的 18–23；③ Phase 2（组句 + 远端清单）新增的 24–29。

## 设计目标

一个默写辅助工具，浅色高雅风格，单窗口桌面应用（Electron）。
画布尺寸统一 **1120×820**，与 Electron 主窗口默认尺寸、Web 端 `max-w-[1120px]` 容器一致；
页面外圈的 `#E6E9EC` 不属于应用内容，故不进设计稿。

**主色**：`$primary #4EA3A0`（青绿）；**辅色**：`$gold #EFC055`（星标/鼓励）。
语义色：`$success #7FB88C` / `$success-bg #EAF4EC`、`$error #DE8071` / `$error-bg #F9EBE8`。

## 伸缩与滚动（弹性区规则）

> 窗口固定 1120×820（高分屏上已占满高度，**不再扩大**）：新功能一律靠“用好既有空间”实现，不靠加高。

**固定区**（任何状态、任何模式下位置都不变）：
`Header 63` → `词源切换条 34` → `词源卡 63` → `Controls 43` → `[错误条 44，仅出错时]` → `Actions 51`

**唯一弹性区**：单词表 / 今日队列卡片（`height: fill_container`）
- 卡内再分两层：**卡头**（`今日队列 · 20 词` + 复习/新词徽标 + `已默 8 / 20` + `重新取词`，固定）与 **列表体**（`fill_container` + `clip`，溢出即滚动）
- 词少时卡片变高（留白在卡内，视觉上是“内容区大”）；词多时卡片**不涨**，改为列表体内部滚动
- 所以：**词再多也不会把 Controls / 按钮顶出界面**；错误条出现时只是这张卡变矮 64px，其它元素纹丝不动

**空态也占满**：`Empty Words` / `Empty Vocab` 两个占位层同样是 `fill_container` 且内容居中——空词库时是“大卡片 + 居中引导”，不是“顶部一行字 + 底部一大块空白”。

**对应实现（Tailwind 口径，照此落）**：
- 根：`flex h-full flex-col gap-5 p-7`
- 弹性卡：`flex flex-1 min-h-0 flex-col`（**`min-h-0` 是关键**，否则 flex 子项不会收缩、滚动失效）
- 列表体：`flex-1 min-h-0 overflow-y-auto`
- 固定行：不加 `flex-1`，保持自然高度
- 空态：在列表体内 `flex h-full items-center justify-center`

**易错点（已规避，改版时别改回去）**：
1. 不让两个兄弟同时 `fill_container`（旧版的“弹性卡 + 底部 Spacer”就是这个问题）——空间分配会互相抢
2. 列表体必须自己 `clip`/`overflow` 承接溢出，不能让卡片自己撑高
3. 条件节点（错误条 / 空态 / 今日队列）必须**互斥**，避免两个 `fill_container` 兄弟同时存在
4. 设置面板加第五张卡就会超过 820 → 已把「倍率调整 / 倒计时数字 / 期望保持率」并成一张 `Params Card` 并收紧内边距，当前总高 779

## 与实现的一处刻意差异：字体

实现里 `--font-heading / --font-body / --font-data` **三者同族**（Sarasa UI SC，Source Han Sans 派生，本机系统字体），
pencil 只能用 Google Fonts，故三个变量统一用 **Noto Sans SC** 代位（同为思源黑体家族，观感最接近）。
如果你希望设计稿恢复「标题衬线 / 数据等宽」的字形区分，那就需要在实现里真正引入对应字体——请审阅时定夺。

## 交互规则（摘自 AGENTS.md，仍是当前实现的口径）

- 每轮时长 = `max(字母数×系数×档位, 音频时长×播报遍数) + 1.5s`；释义模式再加 `释义词数×0.5s`；整体 × 倍率调整
- 播报遍数：释义模式 3 遍；非释义 <6 字母 2 遍、≥6 字母 3 遍
- 跳转解耦：倒计时结束 / 语音播完 各自打标记，两者都完成才进下一轮；
  例外：赛博提交完全部输入后不等倒计时（等当前遍播完即走）、书写模式未发声时按空格可跳
- 对错：仅赛博模式判断，单词严格匹配（trim 后大小写/标点/空格完全一致）；释义与中文词由 AI 批改，失败/中止降级本地宽松匹配并在结果页提示
- 结果页按 Esc 与点关闭完全等价：停止试听并回到准备态，词库保留
- 词库每次新增、批量导入、删除或清空时立即写入 localStorage，刷新或重启后恢复
- 批量导入使用任意空白字符、英文逗号或英文分号切分；忽略空项、本批重复项和已有项
- 键盘流：模式条 ←/→/Home/End 切换；弹层打开即聚焦输入区，`Ctrl/Cmd + Enter` 确认导入，Esc 关闭；`Let's Go!` 自动聚焦回车开始

## Phase 1 界面的补充交互规则（18–23）

- **词源双模式**：切换条只管「词从哪来」，不影响下面的快中慢 / 单词·释义·中文词；切模式不弹任何确认
- **录入模式不进复习**：它是“练一把”的临时路径；想让词有复习计划，先加进词表
- **词表模式不选词**：本场默哪些词完全由 FSRS-6 排（到期优先 + 新词补足），用户只调「今天默几个」（步进器 5–100，默认 20，即改即存）
- **今日队列**：卡头显示总量、复习/新词构成、`已默 x / N`；已默词在胶囊里带勾且变淡；`重新取词`只在队列重新计算时用（不改卡状态）
- **资源词表只读**：没有编辑/删除入口；要改只能 `复制为自建词表`（把资源词表整表拷成自建，再增删）
- **自建词表可编辑**：加词（回车）、批量导入、点词右侧 × 删除；两个导入入口：`从录入的词加入（N）`、`从历史记录导入`；**全部自动去重**
- **键盘流**：20/21 弹层打开即聚焦输入或首个可交互项，Esc 关闭，`Enter` 确认；22 的加词输入框回车即添加且焦点不回跳
- **字体与数字**：队列数量、`已默 x / N`、保持率均用等宽数字（实现里是 `font-data + tabular-nums`）

## Phase 2 界面的补充交互规则（24–29）

- **组句是第四种内容模式**，与单词/释义/中文词并列在同一模式条；与「书写/赛博」正交，但**组句只允许赛博**：
  选中组句时「开始书写默写」置灰（`opacity 0.45`），并在错误条位置显示**信息条**（brand 底色、primary 文字）：
  `组句模式请用赛博默写：选词作答需要在屏幕上完成`
- **候选池**：本场候选词 ≤24 个（词表模式取今日队列前 24 词，录入模式取录入表前 24 词），
  卡头显示`候选词 · N 个（已用 x）`；已被填进某个空的词打勾变淡，**不禁用**（同一个词可能要用两次）
- **组句轮**（27）屏幕结构（自上而下，位置固定）：`第 n / N 题` + `选词作答` 胶囊 → 倒计时条（可选数字）
  → 候选词卡（≤24 个胶囊，2–3 行）→ 短文卡（2–3 句、2–4 个空，句中内联空槽）→ 底部键盘提示行
- **空槽三态**：已填 = 白底 + 1.5px primary 描边 + primary 文字；当前空 = brand 浅底 + 底部 3px primary 下划线 + `选词` 占位；
  未激活的空 = 同样式但下划线为浅灰（设计稿只画了当前空与已填空）
- **键盘流（铁律）**：`←→` 在当前空上移动候选、`1–9` 直接选第 n 个候选、`Enter` 填入当前候选、
  `Tab / ↑↓` 换空、`Backspace` 退回上一个空并清除；**全部空填完立即自动提交**（不需要回车）；
  提示行固定为`←→ 选词 · 1–9 快选 · 回车填入 · Tab 换空 · 倒计时结束按已选提交`
- **倒计时**：与单词轮同一套口径（句长基准 + 每空选择用时，× 档位 × 倍率）；
  倒计时结束时把未选完的空按空字符串提交，随后立即进入下一题
- **结果页（28）**：每个空一行 = 判定图标 + 单词 + 发音按钮 + `句子：…（答案已填入）`，右侧是「我的选择」（绿/红）；
  得分 `x / N` 按空统计；说明行写`每空独立判定：选中与正确词完全一致即算对（忽略首尾空格）`；
  词表模式下右侧同时显示复习写回结果
- **准备阶段（25）**：组句只在准备阶段做一次 AI 请求（`正在出题…（一次性生成整场题目）`），进度条用**不确定样式**
  （设计中用居中短条表示，实现里是来回滑动的动画）；出题成功后**只为答案词合成音频**（结果页发音可用）
- **失败（26）**：出题失败即结束本场，文案`AI 当前不可用：生成的题目不符合要求（本场已停止）`，
  下面一行提示`不降级、不自动重试；返回后可以再点一次开始`，只提供「返回」
- **远端清单（29）**：入口在「选择词表」弹层底部的`检查清单更新`；
  弹层里可填**自定义清单地址**（留空只用随包内置清单；实现里允许 http(s)，但拒本机/内网/保留地址，
  跳转逐跳复校、限大小与超时），检查结果按行给出`更新 / 下载 / 已是最新`，底部`更新可用的 N 个`一次性把有变化的词表拉下来
