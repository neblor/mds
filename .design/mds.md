# 默点啥 mds — 界面设计说明

> 本文件与 `mds.pen` 配套阅读。`.pen` 为加密文件，仅通过 pencil MCP 操作；本文件记录设计意图与功能注解。

## 设计目标

一个默写辅助工具，浅色高雅风格，单窗口桌面应用（deno desktop webview）。

**主色**：浅色背景 + 一个精致的 primary 色 + 辅色（待设计稿定）。

## 界面清单

| 视图 | 说明 | 关键元素 |
| --- | --- | --- |
| 词库管理（准备） | 默认视图 | 标题、单词输入框（回车添加）、输入框右侧批量导入入口、横向 flex-wrap 单词列表（点击删除）、清空按钮、速度三档选择（快/中/慢）、默写内容选择条（单词/释义/中文词，可点击/拖拽/方向键滑动）、`开始书写默写`/`开始赛博默写` 按钮、设置入口 |

## 交互规则（摘自 AGENTS.md）

- 每轮时长 = `max(字母数×系数×档位, 音频时长×播报遍数) + 1.5s`；释义模式再加 `释义词数×0.5s`；整体 × 倍率调整
- 播报遍数：释义模式 3 遍；非释义 <6 字母 2 遍、≥6 字母 3 遍
- 跳转解耦：倒计时结束 / 语音播完 各自打标记，两者都完成才进下一轮
- 对错：仅赛博模式判断，严格匹配（trim 后大小写/标点/空格完全一致）；释义不批改
- 结果关闭后回到准备态，词库保留
- 词库每次新增、批量导入、删除或清空时立即写入浏览器 localStorage，刷新页面或重启 Electron 后恢复
- 批量导入使用任意空白字符（空格、Tab、回车等）、英文逗号或英文分号切分；忽略空项、本批重复项和词库已有项
- 打开批量导入后输入区自动获得焦点；Escape 或点击遮罩关闭，`Ctrl/Cmd + Enter`确认导入
