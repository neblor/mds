## 设计目标与沿用

- 与现有界面同一套浅色高雅风格：`$primary #4EA3A0`、`$gold #EFC055`、
  `$success #7FB88C` / `$success-bg #EAF4EC`、`$error #DE8071` / `$error-bg #F9EBE8`。
- 字体仍用 `font-heading`（单词）/ `font-data`（音标、计数）/ 正文；
  音标 token 用 `font-data`，长音/双元音/塞擦音都是单个 token，不拆字符。
- 主窗口仍 1120×820；音标表走**独立全屏窗口**，不挤在主界面里。

## 主界面（第六项模式）

- `Content Mode Slider` 从 5 项扩到 **6 项**：单词 · 释义 · 中文词 · 短句 · **音标** · 组句；
  宽度 366 → **430px**，避免第 6 项挤压。
- 选中音标时：
  - 「开始书写默写」置灰（`opacity 0.45`），信息条：
    `音标模式请用赛博默写：点选音标需要在屏幕上完成`；
  - 滑块右侧 `ModeActions` 出现 `音标表` 按钮 + `F1` 提示；
  - 准备中/准备完成的遮罩卡也各有一个 `音标表（F1）` 次按钮（准备阶段打开不暂停）。

## 音标轮（默写中）

自上而下：

1. **顶部**：`第 n / N 个` + `音标表` 按钮（小图标）+ 播报状态胶囊
   （`正在播报 · 第 x 遍` / `请作答…` / `播报完成`）。
2. **倒计时条**：与其它模式同一位置；可选 0.1s 数字。
3. **单词卡**：`看单词，点选音标` 小标签 + 大号单词（`font-heading`，30px，
   单行省略、悬停看全文）+ 右侧 `英式` 小胶囊。单词始终可见，这是音标练习而不是拼写默写。
4. **答案条**（固定 `min-h 62px`，不因提示移动）：
   - 空：`从下面点选音标，按顺序拼出这个词…`；
   - 有 chip：每个 chip **左半移除、右半喇叭**，重音 `ˈ`/`ˌ` 的右半是灰点
     `·`（title「重音符号不发音」），不做假喇叭；
   - 右侧 `已放 / 目标`（如 `5 / 5`）；提交后整条变浅绿并出现 ✓。
5. **音标池**：tile **125px 固定宽度**（不随容器压缩）自动换行，1120 窗口 8 列、窄窗口自动降列；池子 `min-height 232px`，行数少时保持与底部操作条的留白，行数多时自然长高；每块 tile **左放入 / 右试听**；
   已使用的池内下标置灰（重复 token 是不同 tile，撤销后只恢复那一块）；
   干扰项与答案一起打乱。
6. **底部操作条**：绝对贴屏幕底、背景同默认 `bg-canvas`、`z-20` 高于池子；池子行数多时藏到操作条后面被遮挡，不把按钮顶出屏幕：
   - 键盘提示：`点选音标 · Enter 选取 · Shift+Enter 试听 · Backspace 撤销 · Ctrl+Enter 提交`；
   - `清空` 次按钮 + `提交` 主按钮（带 `Ctrl+Enter` 小字）。
- 提交后池子与清空禁用，chips 保留；等待语音轨结束或按赛博规则推进。

### 键盘流

- 池子 roving tabindex：←/→/↑/↓（上下步长 = 实际换行列数，`columnsForWidth()` 由
  `ResizeObserver` + DOM 实测 tile 宽度/间距算出）、Home/End、Enter/Space 放入、Shift+Enter 试听；
- 全局：Backspace 撤销最后一块、Shift+Backspace 试听最后一块、Delete 清空、
  Ctrl/Cmd+Enter 提交、F1 开表；
- 每轮开始自动聚焦池子第一块；放入后焦点**顺延到下一个未用的块**（放完落到根容器，
  仍可 Ctrl+Enter 提交）；清空后焦点回池子第一块；音标表关闭后焦点回池子
  （目标块若已用/已提交则兜底到任一可用块）；
- 看表暂停期间主窗口的提交/跳轮全部 no-op。

## 结果页

- 音标行与短句行同级：行首 ✓/✗ + 单词 + `音标` 标签 + 单词发音；
- `标准` 行：token chip 每个都带喇叭（重音无）；
- `我的` 行：用户 token，同样带喇叭；错误行浅红、正确行浅绿；
- AI 兜底词在行首标 `AI 生成，仅供参考`；词典缺失降级的词仍走普通单词行并标
  `本词没有可用音标，按单词默写`；
- 标题右侧保留 `音标表` 入口；结果页打开音标表**不暂停**（已不在默写中）；
- 全对仍走既有撒花。

## 全屏音标表

- 路由 `/phonetic-symbols`：深色 `#0b1220` 底、`object-contain` 居中 3600×2400 原图、
  底部半透明提示「按任意键或点击关闭」；暂停打开时加「默写已暂停 · 」前缀；
- Electron：主进程 `setWindowOpenHandler` 只允许同源、路径精确为 `/phonetic-symbols`，
  用 `createPhoneticWindowOptions()` 开无边框全屏子窗口（`frame:false`、`fullscreen:true`、
  `skipTaskbar`、无 Node 集成）；`did-create-window` 再 `setFullScreen(true)` 兜底；
- Web：普通弹窗（`window.open` 固定内部路径），浏览器地址栏可能保留，不承诺全屏；
- 关闭：子窗口先 `postMessage`，父窗口轮询 `win.closed` 兜底；主窗口恢复倒计时与音频。

## 暂停与音频

- 默写中打开表：倒计时冻结、当前单词音频 abort；关闭后从**当前这一遍**继续
  （`playWithIntervals` 的 `startIndex`），暂停时长不计入本轮 `elapsedMs`；
- 点 chip/pool 喇叭：若单词音频在播/间隔，先 abort，音素播完 120ms 去抖后从当前遍恢复；
  连续点多个只恢复最后一次；提交/推进/进结果/开表不恢复；
- 结果页：单词发音与 token 发音互斥（点一方先停另一方）；同一时间只播一个音素。

## 设计确认（2026-10-23 崔总反馈）

1. **不加重听**；单词/答案/池子整体**顶部对齐**（app `flex-1`，与 `.pen` 34 一致）。
   `.pen` 34 是 flex 自动排布，子节点的 x/y 会被忽略，所以画板里组仍在顶部；
   以 app 实际布局为准。
2. **池子 125px 固定宽度 tile 自动换行（1120 窗口 8 列、747 窗口 5 列）**，不随容器压缩；池子 `min-height 232px`；
   底部操作条贴屏幕底、背景同默认 `bg-canvas`、`z-20` 高于池子，池子行数多时被遮挡，
   不会把按钮顶出屏幕。app 与 `.pen` 34 一致（125px / 1120 窗口 8 列 / min-height 232）。
3. **结果行保持现状**（不改成左右并排）。
4. **Web 标题不改**；音标表本来就是独立窗口：Electron 无边框全屏子窗口，Web 普通弹窗。

以上 4 点已定稿，不再作为待确认项；`.pen` 34 与 app 现在都是顶部对齐，如需再居中可后续加 spacer。
