# 默点啥 v1.0.0

第一个正式版本。这一个版本之前，它一直是我们自己用的默写小工具；从 1.0.0 起，安装包会作为 GitHub Release 公开发布，
后续版本都从这里下载。

## 七种默写内容

一条可滑动的选择条切换默写什么：

- **单词**：只默单词本身，看发音写拼写。
- **释义**：先写单词，再写英文释义（AI 批改，意思相同即算对）。
- **中文词**：先写单词，再写中文对应词（同样由 AI 批改）。
- **短句**：默写整句（目标 3–6 词、最多 8 词）；只念整句 3 遍，判定按整句归一化比较，
  大小写、标点和多余空格都不影响结果。
- **混合**：每个词在释义 / 中文词 / 短句里随机取两种，20 个词就是 40 轮；
  同一个词的第二次出现只写第二步（释义或中文词），不重复考拼写。
- **音标**：从音标块池里拼出读音，主重音必须拼对；内置英式音标词典，未收录的词可用 AI 兜底，
  还带音素试听和全屏音标表。
- **组句**：选词作答，一轮多个空。

书写默写（自己用纸笔）与赛博默写（在屏幕上打字）都支持；音标与组句只能赛博。

## 词库与学习档案

- 词库按 FSRS 排期取词：到期复习的优先，其次是没学过的新词；「本次取几个词」可以在 5–30 之间按 5 递增。
- 每个词库一份学习档案：掌握进度、近 7/30 天正确率、180 天练习热力、14 天到期预测、薄弱词与常练词，
  底部还能一键「专练薄弱词」。
- 复习状态存在本地 SQLite（`mds-data/review/review.sqlite`），关掉应用再打开不会丢；
  旧版本的 JSON 数据在首次启动时自动迁移，原文件归档保留。

## 默写过程

- 语音用 Edge TTS 预生成并缓存，准备阶段显示进度，准备完成后按 `Let's Go!` 开始。
- 倒计时与语音播放解耦：倒计时结束和这一轮语音播完，两个条件都满足才进入下一轮；
  赛博默写提前写完可以直接提交，书写默写可以在语音停止时按空格跳过。
- 键盘优先：准备、作答、批改、结果、关闭整条链路都能只用键盘走完。
- 结果页按模式给出对错、参考内容和每个词的发音（同一时间只播一个）；单词全对会有庆祝动画。

## 安装

- 下载 `mds-1.0.0-setup.exe`，引导式安装，仅当前用户，可选安装目录，开始菜单快捷方式「默点啥」。
- 卸载默认保留用户数据（词库与复习状态）。
- 本版本**没有代码签名**，首次运行 Windows 会提示「未知发布者」，属预期；下载页同时提供 `SHA256SUMS.txt`
  供核对文件完整性。

## 需要 AI 配置的功能

释义、中文词、短句、组句以及音标兜底需要在应用设置里填写 OpenAI 兼容的 Base URL、API Key 与模型名。
配置只保存在本机。不配置时「单词」与「音标」（词典覆盖范围内）照常可用，
释义 / 中文词 / 短句 / 混合 / 组句会提示先配置 AI。
