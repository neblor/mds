# 默点啥 v1.0.1

这一版**没有新增或改变任何默写功能**，只做了内部加固与诊断整理；从 1.0.0 升级不需要迁移数据，
词库、学习档案和复习进度都原样保留。

## 变更

- **交付检查加了一道类型关卡**：`pnpm check` 现在会先跑 `tsc --noEmit`，再打包；
  类型问题不再拖到运行时才暴露。
- **诊断日志改名**：`mds-data/logs/ai-definitions.log` → `runtime.log`。
  这个文件里早就不只有 AI 释义了（还有 TTS 等事件），旧名字容易误导排查方向。
  旧文件（含轮换的 `.1`）会在首次写入时自动搬过去，不会丢历史记录。
- **发版流程加固**：安装包归档改为「暂存目录写满 + 全量校验后再落成正式目录」，
  归档失败会把安装包退回原处，不会出现「目录在、包没了」；同时避免误删另一场正在进行的发布。
- **打包提示文案修正**：按当前版本正式打包时不再打印「测试打包完成」。

## 安装

- 下载 `mds-1.0.1-setup.exe`，覆盖安装即可；卸载仍然默认保留用户数据。
- 本版本**没有代码签名**，首次运行 Windows 会提示「未知发布者」，属预期；
  下载页同时提供 `SHA256SUMS.txt` 供核对文件完整性。
