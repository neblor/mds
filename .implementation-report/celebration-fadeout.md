# 全对庆祝效果补全消失生命周期

> 日期：2026-08-29 · 触发：用户反馈结算画面星星和光晕一直不消失

## 问题

`ResultsView` 全对庆祝的三个元素中两个"永驻"：

1. **顶部柔光**：静态元素无任何动画，常驻显示
2. **中心礼花**（`sparkle-pop`）：关键帧终点 `opacity:1; scale(1)` + `forwards`，播完停在最终帧永可见
3. 波次星星（`celebrate-rise`）本身会淡出，但填充模式只有 `forwards`，`animation-delay` 期间以全不透明静态呆在起始位（先闪现再动的小瑕疵）

## 修复（`src/app.css` + `ResultsView.tsx` 柔光节点）

按"持续一段时间后收缩渐淡消失"重排生命周期，整体 ~3.5s 收尾（与第二波星星 ~3.6s 对齐）：

- 波次星星：`forwards` → `both`（延迟期保持 0% 不可见，结束后保持消失）
- 中心礼花：1.1s 弹跳 → 3.2s 全周期（弹跳 ~1s → 停留至 72% → `ease-in` 收缩至 scale 0.25 并淡出至 0）
- 顶部柔光：新增 `celebrate-glow` 3.4s（亮起 → 停留微涨 → 收缩至 0.55 并淡出至 0）

**关键坑**：柔光原用 Tailwind `-translate-x-1/2` 居中；Tailwind v4 的 translate 工具走独立 `translate` 属性，会与 keyframe 的 `transform` **叠加**造成双重位移。改为 `ml-[-9rem]`（w-72 的一半）负 margin 居中，keyframe 只动 scale。

## 验证

- `pnpm check` 全绿（321 测试 + 构建 + 冒烟）
- 生产服务 + playwright 截图（播种全对历史 → 历史详情触发庆祝）：金色像素 1s=806 → 2.5s=264 → **5.2s=0**，完全消失
- 柔光浅金晕质心 x=557（画布中点 560），居中无误

## 备注

纯 CSS 动画参数调整，无逻辑变更，无新增单测（视觉时序由截图像素分析验证）。`.pen` 不表达动画时序参数，未更新设计文件。
